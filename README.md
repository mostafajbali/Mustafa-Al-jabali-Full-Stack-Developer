## 🌟 الميزات الرئيسية (Key Features)

- **هوية بصرية تقنية حديثة (Cyber-Tech & Developer Palette)**: تصميم احترافي بشبكة هندسية دقيقة وألوان تقنية متناسقة.
- **تجاوب كامل 100% (Fully Responsive)**: تجربة مستخدم سلسة على الجوال، التابلت، اللابتوب، والشاشات العريضة.
- **دعم ثنائي اللغة (AR / EN Bilingual)**: التبديل الفوري بين العربية الفصحى والإنجليزية الصافية.
- **معرض أعمال تفاعلي (Interactive Projects Portfolio)**:
  - منصة وموقع روضتي لرياض الأطفال (`Rawdati Platform`).
  - متجر تسوق وتجارة إلكترونية متكامل (`NovaMart E-Commerce`).
  - نظام منيو مطاعم إلكتروني تفاعلي مع شاشات المطبخ الذكية (`GustoQR`).
- **لوحة تحكم إدارية مستقلة (Admin Dashboard)**: إدارة وتعديل المشاريع، المهارات، وروابط التواصل بسهولة.
- **تواصل فوري ومباشر**: زر WhatsApp عائم، اتصال مباشر، وروابط GitHub و LinkedIn.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons
- **Backend**: Node.js, Express.js
- **Build Tool**: Vite, TSX
- **Data Persistence**: JSON-based Flat File DB (`/data/portfolio_db.json`)

## 🚀 تشغيل المشروع محلياً (Local Development)

### 1. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 2. تشغيل خادم التطوير (Start Dev Server)
```bash
npm run dev
```
الموقع سيعمل مباشرة على الرابط: `http://localhost:3000`

### 3. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
npm start
```
